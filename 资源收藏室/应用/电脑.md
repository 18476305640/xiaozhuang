开始：
### 1、前置环境开启
1.1 开启WSL
控制面板-程序-启用或关闭Windows功能-适用于Windows的Linux子系统（开启）
1.2 并为避免出现“**wsl 请启用“虚拟机平台”可选组件，并确保在 BIOS 中启用虚拟化。**”，请在命令行中执行`bcdedit /set hypervisorlaunchtype auto`
1.3 重启电脑（上面每一步修改都需要重启）!!!

```bash
wsl --set-default-version 2
```

## 常见场景
### 1、add错了
#全部撤回
git reset HEAD .
#只撤回某个文件 git reset HEAD package-lock.json
### 2、commit错了还没push
#直接撤销？找到最近第二个commitId `git reset <commitId>`
#message信息写错了？ `git commit --amend -m "新的提交说明"`
#漏了文件？`git add forgotten.java && git commit --amend --no-edit`
### 3、2、commit错了且已经push
git push origin master --force-with-lease`  #为什么用 --force-with-lease 而不是 --force？前者会检查远端有没有人比你先 push，避免把同事的 commit 冲掉，更安全。
### 4、rebase与merge 分别在什么场景下使用
rebase：当非分支合并时建议都使用rebase （防止多人开发时产生过多无用的merge信息），rebase的原理是将当前自己的修改放一边先将远程的commit拉过来，再将自己的放在上面，默认的git pull等同于git fetch && git merge，会多出一个分支merge信息，可以配置默认git pull时默认git pull --rebase。

    ```au3
    #include <FileConstants.au3>
    #include <MsgBoxConstants.au3>

    Func RunCmdArray(ByRef $aCommands, $bAdmin = False, $bShowWindow = False)
        If Not IsArray($aCommands) Then
            MsgBox($MB_ICONERROR, "错误", "传入参数不是数组")
            Return False
        EndIf

        Local $sTmpBat = @ScriptDir & "\tmp_cmd.bat"

        ; 写入批处理文件，强制使用 ANSI（GBK）避免中文乱码
        Local $hFile = FileOpen($sTmpBat, $FO_OVERWRITE + $FO_CREATEPATH)
        If $hFile = -1 Then
            MsgBox($MB_ICONERROR, "错误", "无法创建临时文件: " & $sTmpBat)
            Return False
        EndIf

        FileWriteLine($hFile, "@echo off")
        ; 设置 cmd 默认代码页为 65001 (UTF-8) 如果希望用 UTF-8
        ; FileWriteLine($hFile, "chcp 65001 >nul")
        For $i = 0 To UBound($aCommands) - 1
            FileWriteLine($hFile, $aCommands[$i])
        Next
        FileClose($hFile)

        ; 执行命令
        Local $iSW = $bShowWindow ? @SW_SHOW : @SW_HIDE
        If $bAdmin Then
            ; 管理员权限执行（异步）
            ShellExecute($sTmpBat, "", @ScriptDir, "runas")
            Sleep(3000) ; 可根据实际调整等待 UAC 弹出
        Else
            ; 普通权限，RunWait 会等待执行完
            RunWait(@ComSpec & " /c " & '"' & $sTmpBat & '"', @ScriptDir, $iSW)
        EndIf

        FileDelete($sTmpBat)
        Return True
    EndFunc
    ```
