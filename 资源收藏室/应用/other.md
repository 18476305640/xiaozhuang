# 国外支付-虚拟卡（chrome插件注册费5美元、自己注册美区AppId与购买Shadowrocket）
前置知识：
- USDT/USDC是稳定的加密货币，其价值几乎 1USDT/USDC == 1USD（美元）


1）在“[欧易](https://www.okx.com/cn/download)”购买USDT/USDC -> 在“欧易”中提币到[onekey card](https://card.onekey.so/)（需要消耗0.8~1 USDT） -> 在onekey card将充值的USDT/USDC转为USD（美元）->在onekey card开卡(开卡至少20USD会充到卡中+手续费1USD)

步骤相关教程：[欧易操作教程](https://chatgpt-plus.github.io/chatgpt-plus/#3%E3%80%81%E7%94%B3%E8%AF%B7%E8%99%9A%E6%8B%9F%E4%BF%A1%E7%94%A8%E5%8D%A1Depay)、[onekey card相关教程](https://juejin.cn/post/7223343320298324029)

2）经过以上就有了一张虚拟卡，就可以用于google支付chrome插件注册费5美元，可以用于注册美区的AppId（自然也需要绑定卡，会比较稳定，不然不绑卡，后面可能账号被停），绑定了卡那只要卡里有钱，那直接就购买了安装Shadowrocket了！

步骤相关教程：[注册美区AppId教程](https://zhuanlan.zhihu.com/p/367821925)

<details> <summary>frp内网穿透（你需要有一个公网的服务器）</summary>
如何实现泛域名映射
1、域名解析到服务器 2、客户端配置如下：
frpc.toml
```txt
serverAddr = "50.114.152.151"
serverPort = 7000


[[proxies]]
name = "web"
type = "http"
localIP = "localhost"
localPort = 5000
customDomains = ["test.frp.xxx.yyy"]
```
frps.toml
```txt
bindPort = 7000
vhostHTTPPort = 8080
#访问控制面板的端口号
webServer.port = 7500
#控制面板的用户名和密码，暴露在公网的服务请使用严谨一些的用户名密码
webServer.user = "admin"
```
启动客户端`frpc.exe -c frpc.toml`，访问`test.frp.xxx.yyy` -> 客户端`localhost:5000`

我们将会创建一个raw格式的虚拟磁盘，并挂载到您的系统上，命令如下：（下面的seek=后跟的是您想要创建的磁盘大小，这里大约是20G，这个命令会创建一个松散文件，不会占用您的磁盘空间，它会随着写入数据而增大。）（想超售？那就拉大虚拟磁盘）

```md
nginx/
- ngin.conf : 配置的入口文件，其它子配置会从这里includes, 默认include下面两个：
      include /etc/nginx/conf.d/*.conf;
      include /etc/nginx/sites-enabled/*;
- conf.d/ ：nginx自己的代理访问配置放在这里，如果没有这个配置，就无法访问NginUI的管理面板
- sites-available/ ：在nginxUI创建的“网站”是以一个文件放在这里的，如果我们“开启”这个网站后，那会创建一个软链接放在`sites-enabled/`下面，那这个网站配置就生效了。
- sites-enabled/ : 存放生效/开启的的网站配置，详细请看`sites-available/`

...其它配置文件
```

1、docke-compoe部署
> 如果你当前的有服务占用着80与443端口，你可以将下面修改为其它端口，等迁移到nginxUI后再停止原来的nginx，再将端口改回为80与443。
```bash
cat << EOF > docker-compose.yml

services:
  nginx-ui:
    image: uozi/nginx-ui:latest
    container_name: nginx-ui
    restart: always
    environment:
      - TZ=Asia/Shanghai
    volumes:
      # 当前目录下的 nginx 文件夹映射到容器内的 /etc/nginx
      - ./nginx:/etc/nginx
      - ./ssl:/etc/ssl
      # 当前目录下的 nginx-ui 文件夹映射到容器内的 /etc/nginx-ui
      - ./nginx-ui:/etc/nginx-ui
      # 当前目录下的 www 文件夹映射到容器内的 /var/www
      - ./www:/var/www
      # 保持 Docker 套接字映射（用于容器管理功能）
      - /var/run/docker.sock:/var/run/docker.sock
    ports:
      - "80:80"
      - "443:443"
    
EOF
docker-compose up -d

docker-compose down #关闭进行修改上面初始出来的配置
```
